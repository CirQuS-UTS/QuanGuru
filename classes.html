Classes (quanguru.classes)#

This module contains objects

Contains two main base classes (for naming and sub/superSys) and their helper classes, functions, decorators.

Contains some base classes.

QSystem

Contains the QuantumSystem class used for quantum systems

QTerms

Contains the QTerm object that is used for the terms of the quantum system Hamiltonians

QSim

Contains Simulation and _poolMemory classes.

QPro

Contains the classes for protocols.

QRes

Contains qResults, qResBase, and qResBlank classes used in storing various types of simulation results.

Contains two classes used for sweep functionalities.
